## Deskripsi Repository
Repository ini dibuat untuk memenuhi tugas Pemrograman Dasar dari rangkaian kegiatan TETI Lab Skill (TLS) 2026. Di dalam repository ini, terdapat penyelesaian dari dua buah masalah pemrograman:
1. **The Last Astronaut:** Algoritma eliminasi melingkar dengan aturan pergeseran dinamis (genap/ganjil) untuk mencari astronot terakhir yang bertahan.
2. **Alien-In-The-Middle (Sandi Caesar Dinamis):** Algoritma kriptografi sederhana yang menggeser karakter alfabet berdasarkan nilai karakter asli tepat di urutan sebelumnya.

## Isi Repository
Penyelesaian tugas ini dibagi menjadi dua fase yang file-nya dapat ditemukan di dalam repository ini:
* **Fase 1 (Logika):** Dokumen berformat `.pdf` yang berisi rancangan algoritma berupa Pseudocode dan Flowchart beserta penjelasan logikanya untuk kedua problem.
* **Fase 2 (Implementasi Kode):** Dua buah file *source code* berbasis bahasa C++ (`.cpp`) yang mengimplementasikan logika dari Fase 1 dengan hanya menggunakan library standar `<iostream>` dan *user-defined function*.
